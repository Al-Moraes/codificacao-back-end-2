# Aula 01 - Diagnóstico do Sistema com Módulo Native `os`

> Script simples em Node.js para extrair e exibir informações do sistema operacional e hardware no terminal.

## Conteúdo Praticado

- Importação e uso de módulos nativos do Node.js (`require('os')`)
- Manipulação de dados de hardware (CPU, Memória RAM e Plataforma)
- Conversão de bytes para Gigabytes (`GB`) e formatação de decimais (`.toFixed()`)
